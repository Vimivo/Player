# Vimivo 1.0.0 release notes

First release candidate of Vimivo, a private, ad-free local music and video player. It includes local library browsing, background music controls, fullscreen video playback, playlists and favorites, subtitles and audio-track selection, authorized network streams, themes, accessibility settings, and local backup/restore.

Playback format support varies by device, codec, file composition, and engine. This build should remain on internal testing until the blockers in `RELEASE_CHECKLIST.md` are closed.
