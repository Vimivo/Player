# Production Readiness Assessment

Status overview across all five supported platform targets as of 2026-10-15 (Milestones 23 & 24 Complete).

| Platform | Technical & Quality Status | Distribution & Production Release Readiness |
|---|---|---|
| **Android** | Production Hardened | Fully functional release APK (`androidApp-release-unsigned.apk`, 141 MB) and release App Bundle (`androidApp-release.aab`, 73 MB). All unit tests (20/20) and Detekt static analysis pass. Media3 foreground service, MediaSession, TalkBack accessibility, and Android 13+ notification permissions verified. Store submission requires owner-managed upload keystore. |
| **iOS / iPadOS** | Implemented & Simulator Verified | Native SwiftUI application with shared Kotlin framework (`VimivoShared.framework`), AVFoundation audio/video playback, background playback (`UIBackgroundModes: ["audio"]`), Lock Screen / Control Center integration (`MPNowPlayingInfoCenter`, `MPRemoteCommandCenter`), PiP (`AVKit`), sandboxed Files access (`SecurityScopedMediaManager`), native SQLite persistence in WAL mode (`IOSDatabase`), and Keychain credential storage (`KeychainCredentialStore`). Unit tests (7/7) passed on iPhone 17 Pro and iPad Pro simulators. VoiceOver accessibility verified. App Store submission requires owner-managed Apple Developer certificate and provisioning profile. |
| **macOS** | Implemented & Package Verified | Standalone application (`Vimivo.app`) and installable DMG (`Vimivo-1.0.0.dmg`) with self-contained JVM and 50-dylib native closure are implemented and verified. Responsive sidebar, theme switching, SQLite persistence, and keyboard navigation verified. Public distribution gate remains blocked on Apple Developer ID certificate signing, Hardened Runtime, and notarization. |
| **Windows** | Implemented, Host Required | Embedded video renderer (`MpvWin32Renderer`), secure DLL loading, Windows Credential Manager, desktop shortcuts/drag-and-drop, and standalone packaging (EXE/MSI) configuration are implemented and test-verified. Packaging execution and clean-environment playback verification require a Windows host/runner. Authenticode signing remains blocked on signing credentials. |
| **Linux** | Implemented, Host Required | Embedded video renderer (`MpvX11Renderer`), MPRIS 2 D-Bus media integration, Freedesktop Secret Service credential store, desktop shortcuts/drag-and-drop, AppImage/Flatpak/DEB/RPM packaging configuration, and Linux CI workflow are implemented and test-verified. Packaging execution and clean-environment playback verification require a Linux host/runner. |

Passing compilation or JVM unit tests does not satisfy the native runtime, installation, security, licensing, accessibility, or signing gates. Real physical device testing and owner-managed release code signing are required for production store submissions.
