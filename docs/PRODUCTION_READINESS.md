# Production readiness

Status overview across all supported platforms.

| Platform | Technical status | Distribution / Release status & Primary Blockers |
|---|---|---|
| Android (Milestone 21) | Production Hardened | Release unsigned APK (`androidApp-release-unsigned.apk`, 141 MB) and release App Bundle (`androidApp-release.aab`, 73 MB) built and verified. Unit tests (20/20) and Detekt static analysis passed. Android 13+ `POST_NOTIFICATIONS` integrated for media service foreground notifications. Target SDK 36 (Android 16). Public Google Play upload blocked only on owner-managed release signing keystore and production Play Console upload. |
| iOS / iPadOS (Milestone 22) | Implemented & Simulator Verified | Native SwiftUI mobile application with shared Kotlin framework (`VimivoShared.framework`), AVFoundation audio/video playback, background playback (`UIBackgroundModes: ["audio"]`), Lock Screen / Control Center integration (`MPNowPlayingInfoCenter`, `MPRemoteCommandCenter`), PiP (`AVKit`), sandboxed Files access (`SecurityScopedMediaManager`), native SQLite persistence in WAL mode (`IOSDatabase`), and Keychain credential storage (`KeychainCredentialStore`). Simulator unit tests (7/7) passed on iPhone 17 Pro and iPad Pro simulators. Release build succeeded. Public distribution (App Store / TestFlight) blocked on owner-managed Apple Developer certificate and provisioning profile. |
| macOS | Implemented & Package Verified | Standalone application (`Vimivo.app`) and installable DMG (`Vimivo-1.0.0.dmg`) with self-contained JVM and 50-dylib native closure are implemented and verified. Public distribution gate remains blocked on Apple Developer ID certificate signing, Hardened Runtime, and notarization. |
| Windows | Implemented, Host Required | Embedded video renderer, secure DLL loading, Windows Credential Manager, desktop shortcuts/drag-and-drop, and standalone packaging (EXE/MSI) configuration are implemented and test-verified. Packaging execution and clean-environment playback verification require a Windows host/runner. Authenticode signing remains blocked on signing credentials. |
| Linux | Implemented, Host Required | Embedded video renderer, MPRIS 2 D-Bus media integration, Freedesktop Secret Service credential store, desktop shortcuts/drag-and-drop, AppImage/Flatpak/DEB/RPM packaging configuration, and Linux CI workflow are implemented and test-verified. Packaging execution and clean-environment playback verification require a Linux host/runner. |

Passing compilation or JVM unit tests does not satisfy the native runtime, installation, security, licensing, accessibility, or signing gates. Real physical device testing and owner-managed release code signing are required for production store submissions.
