# Desktop Video panel: crop, deinterlace modes, hue (V1 #12, #13, #14)

macOS, packaged app with the LGPL media package (`media-1`), `--smoke-test --ui-capture`.
`video-panel-crop-deinterlace-hue.png` shows the new **Crop** and **Deinterlace** dropdowns and the **Hue** slider.

Live tests (real libmpv), all in `desktopApp/src/desktopTest/.../playback/`:

| Test | What it proves |
|---|---|
| `MpvBlackBarDetectionTest` | `bbox` finds the 320x180 picture inside 30-row bars: `x=0 y=30 w=320 h=180` of a 320x240 frame; a clip without bars yields the whole frame |
| `MpvVideoFiltersLiveTest.aCropIsAppliedAndCleared` | `video-crop` = `320x180+0+30`, then cleared |
| `MpvVideoFiltersLiveTest.hueReachesLibmpv` | `hue` round-trips |
| `MpvVideoFiltersLiveTest.everyDeinterlacingModeIsAcceptedAndPlaybackContinues` | each mode installs exactly one `@vimivo-deint` filter (none for Off) and playback keeps moving |
| `MpvDeinterlaceEffectTest` | combing metric (neighbour-row difference / two-rows-apart difference) on a frame of the combed fixture: 71.9 without a filter, then AUTO 0.50, BWDIF 0.50, W3FDIF 0.50, ESTDIF 0.50, YADIF 1.60 |

Unit tests (shared): `VideoCropMathTest` (preset geometry, even sizes, thin bars ignored), `DeinterlaceModeTest` (only
LGPL filters that `verify.py` checks; `mcdeint`/`kerndeint` absent).

Fixtures (generated by `testmedia/generate_media.py`, all under 200 KB): `letterbox_tiny.mp4`, `interlaced_tiny.ts`.
