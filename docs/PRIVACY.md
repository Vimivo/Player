# Vimivo privacy policy

Effective date: 2026-10-13

Vimivo is an offline-first music and video player. It does not require an account and does not include advertising, analytics, behavioral tracking, or a Vimivo-operated backend.

## Information processed on your device

With your permission, Vimivo indexes media metadata exposed by Android MediaStore, such as titles, artists, albums, folders, durations, file properties, and artwork references. Vimivo also stores your settings, playlists, favorites, bookmarks, playback history, queue, and resume positions locally on your device. Media files are not copied into Vimivo's database or local backups.

You may avoid broad audio/video library access and open individual files or folders with Android's system picker. Persisted picker access is retained only when Android grants it and can be revoked through system settings or by removing the selected location.

## Network streams

Vimivo connects directly to an HTTP or HTTPS address only when you choose a stream or remote media URL. The destination server and network provider may receive normal connection information such as your IP address, request headers, and requested URL under their own policies. Vimivo does not send the URL to a Vimivo server or a third-party catalog. HTTP is unencrypted; use HTTPS whenever available.

Recent and favorite stream URLs are stored locally. Avoid saving URLs containing credentials or private tokens. You can clear recent streams in Settings.

## Permissions

Audio and video permissions support optional shared-media discovery. Legacy storage access is limited to Android versions that require it. Internet and network-state access support user-initiated streams. Foreground media playback permissions keep active playback available with a visible system notification. Vimivo does not request all-files access.

## Backups and deletion

Android cloud/device backup is disabled for Vimivo. A local backup is created only when you explicitly choose an export destination through Android's system document picker. It may contain settings, playlists, favorites, bookmarks, history, and media references, but not media files. Anyone with access to that exported file may read it; protect it appropriately.

Settings provides controls to clear playback history, recent streams, cached artwork, settings, or all local application data. Uninstalling the app removes its private local data, but exported backup files remain where you saved them.

## Children, changes, and contact

Vimivo is a general-purpose media utility and is not specifically directed to children. This policy will be updated when data practices materially change; the effective date will be revised.
