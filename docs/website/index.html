Lossless Audio Fidelity

Native bit-perfect playback for FLAC, ALAC, WAV, and high-bitrate MP3/AAC up to 24-bit 192kHz.

Hardware Video Acceleration

Direct surface attachment via libmpv, MediaCodec, and VideoToolbox for silky 4K/60fps playback.

Continuous Unified Queue

A smart playback queue that remembers its place across application restarts with zero data loss.

Built-in diagnostic exporter redacts all username paths and URL tokens before saving locally.
